BrainHarness data

Chats, settings, memory, tool evidence and local logs stay in your chosen BrainHarness data directory. BrainHarness application analytics and remote trace exporters are disabled.

The selected model provider receives the context needed for each request. Provider authentication, MCP servers, research services, browser automation and computer-use services communicate with the services you configure. Their own data policies apply. Tool observations and original user requests are retained locally for memory retrieval.

API keys use the provider credential store or protected provider environment settings. OAuth opens the chosen provider's authentication flow. BrainHarness does not require a hosted application account.
